How to Use

To use System7 web components in your project:

1. Install the module:

npm install system7

2. Import in your JavaScript:

import { System7Component } from 'system7';
import 'system7/src/hello-world.js';

3. Create your own components:

class MyComponent extends System7Component {
  render() {
    this.shadowRoot.innerHTML = `
      <style>
        :host { display: block; }
      </style>
      <h2>My Custom Component</h2>
    `;
  }
}

customElements.define('my-component', MyComponent);
